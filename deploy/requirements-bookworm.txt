# Runtime requirements for Raspberry Pi OS bookworm (Python 3.11).
# Proposal next to the old ../requirements.txt, which stays untouched (it still
# serves the old Bullseye/Python 3.9 Pi). deploy/provision.sh installs THIS file.
#
# Why it differs from requirements.txt (found in the container spike, aarch64,
# Python 3.11.2, gcc 12):
#   RPi.GPIO==0.7.0   does not build any more ("multiple definition", gcc >= 10) -> 0.7.1
#   board==0.0.0.post0 is a PyPI placeholder without board.D18 and it shadows the
#                      real "board" module of Adafruit-Blinka -> removed, Blinka added
#   adafruit-circuitpython-neopixel==6.0.0 pulls an old Blinka -> current release
#   numpy             is imported by conf/hx711.py but was never listed -> added
#   rpi_ws281x        PWM driver behind Blinka's neopixel_write on Pi 3/4 -> added
#   spidev, requests, pytest and the other old pins are not needed at runtime -> dropped
#
# Tested versions (container, no hardware): paho-mqtt 1.6.1, webcolors 1.3,
# RPi.GPIO 0.7.1, Adafruit-Blinka 10.2.0, rpi-ws281x 5.0.0,
# adafruit-circuitpython-neopixel 6.4.2, numpy 2.4.6.
#
# Pi 5: RPi.GPIO does not work there; replace it with "rpi-lgpio" (drop-in).
